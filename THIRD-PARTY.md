## Maintaining this file

When adding an artifact that vendors third-party source:

1. Keep the upstream copyright/license header **verbatim** — never rewrite it to
   the cMeta header.
2. Ship the upstream license text inside the artifact (e.g. `src/LICENSE.txt`).
3. Add a row to the summary table and a section here.
4. If its terms are more restrictive than Apache-2.0, say so explicitly.

Prefer **fetching** third-party sources at run time (via a `clone-git-to-cache`
or download task) over vendoring them — it avoids redistribution questions
entirely.
